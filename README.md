# PawPath

A local, full-stack dynamic website for reporting, fostering, rescuing and adopting stray animals.

## Run locally

1. Open this folder in VS Code.
2. In its terminal, run `npm install`.
3. Seed the database: `npm run seed`.
4. Start the website: `npm start`.
5. Open `http://localhost:3000` in a browser.

## What this demonstrates

- Session-based login/signup with hashed passwords and a server-checked maths CAPTCHA.
- Client-side JavaScript and server-side form validation.
- SQLite database with users, animals, applications, and rescue updates.
- CRUD: create/read/update/delete animal profiles and rescue updates.
- Search, filters, sorting, responsive UI, ownership checks, status updates and adoption/foster help offers.
